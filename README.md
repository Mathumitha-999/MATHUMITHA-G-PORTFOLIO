# Mathumitha G · Portfolio

Personal portfolio of **Mathumitha G**, final-year Computer Science and Engineering student at DMI Engineering College and full-stack developer (React, Node.js, Spring Boot, MongoDB, MySQL).

**Live site:** https://mathumitha-999.github.io/MATHUMITHA-G-PORTFOLIO/

## What's on the page

- **Portfolio API console:** browse profile, experience, projects, skills, education and contact as JSON responses.
- **Experience:** internships at J Click Solutions, Coptercode (IIT Madras Research Park) and OpsMonsters.
- **Projects:** Hospital, Montessori School, Hotel, Certificate and Student Management Systems, and the Neem Tech Solution website.
- **Interview request form:** companies can send interview details. Until an email key is set, it opens a pre-filled Gmail message to mathumgk999@gmail.com.
- Light and dark themes, a custom pointer, and a layout that works on phones.

## Built with

HTML, CSS and plain JavaScript in a single `index.html` file, with no build step. Fonts come from Google Fonts, and the technology logos are from Simple Icons.

## Optional setup

Open `index.html` and edit these two lines near the start of the script:

```js
const WEB3FORMS_KEY = '';                        // free key from web3forms.com → interview requests arrive by email
const NTFY_TOPIC = 'mathumitha-hr-4264032532';   // subscribe to this topic in the ntfy app → phone alerts
```

With `WEB3FORMS_KEY` empty, the form opens Gmail instead of sending automatically.
